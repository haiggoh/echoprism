## 6. Smart Episode Linking — Specification

**Trigger:** On WiFi + charging (or user-enabled "background sync")

**Process:**
1. For each subscribed podcast RSS feed → search YouTube for channel matching podcast title/author
2. For each YouTube subscription → check if channel has podcast RSS (many podcasters publish both)
3. Match episodes by: normalized title similarity (Levenshtein/fuzzy), publish date proximity (±3 days), duration similarity (±10%)
4. Store matches locally in SQLite: `episode_links(podcast_guid, youtube_video_id, confidence, matched_at)`
5. UI: In queue/player, show "🔗 Video version" or "🔗 Audio version" button when match exists
6. One-tap switch: preserves playback position (rough sync via timestamp %)

**Matching Heuristics:**
- Exact title match after normalization (remove ep numbers, special chars) → high confidence
- Fuzzy match (80%+ similarity) + same publish week → medium confidence
- Manual override: user can link/unlink, corrections improve future matches

**Privacy:** All matching runs locally on device. No episode data leaves device. YouTube searches via Invidious instance (no Google API key).
